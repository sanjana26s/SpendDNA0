# 🧬 SpendDNA – Your Wallet's Year-End Story

### Personal Transaction Analysis & Spending Personality Detection

## 📌 About the Project
SpendDNA is a Python-based financial analytics project that transforms raw bank transaction data into meaningful insights about spending habits, financial trends, vendor activity, and spending personality.

It analyses transactions to identify where money is spent, how spending changes over time, unusual transactions, and behavioural patterns.

## 🎯 Objectives
- Clean and preprocess raw transaction data.
- Extract and identify vendors from transaction descriptions.
- Automatically categorise transactions.
- Analyse spending and income patterns.
- Track monthly spending trends.
- Understand spending behaviour by time of day.
- Detect unusually high transactions.
- Identify spending personality archetypes.

## ✨ Features

### 1. Transaction Parser
Cleans transaction data, standardises dates, amounts and transaction types, and removes duplicate records.

### 2. Vendor Extractor
Extracts and identifies vendors from raw transaction descriptions.

### 3. Category Tagger
Classifies transactions into meaningful financial categories.

### 4. Spending Overview
Analyses total spending, income, net cash flow, transaction counts, and top spending categories and vendors.

### 5. Monthly Spending Trends
Examines monthly expenditure and identifies spending increases and decreases.

### 6. Time-of-Day Analysis
Analyses spending patterns across different hours of the day.

### 7. Anomaly Detection
Uses statistical analysis and Z-scores to identify unusually high transactions within spending categories.

### 8. Spending Personality
Identifies behavioural archetypes based on spending patterns.
